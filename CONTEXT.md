# כמה נגמר? — Domain Glossary

Language of the site: Hebrew. Canonical Hebrew labels appear beside each term.

| Term | Meaning |
|------|---------|
| **Episode** (פרק) | A daily podcast episode. Lives on Spotify/Apple Podcasts — the site embeds and links to episodes, it never hosts audio. |
| **Article** (כתבה) | A published written piece: title, subtitle, cover image, author, tags, and ordered content blocks. |
| **Block** | One unit of article content: paragraph, heading, image, or video embed. |
| **Draft / Published** (טיוטה / פורסם) | Article visibility states. Only published articles exist for readers, feeds, and rankings. |
| **Subject** (נושא) | One of a short, admin-curated list of sections readers navigate by (כדורגל ישראלי, כדורגל עולמי, כדורסל, ספורט אולימפי, מוטורספורט). An article belongs to its primary subject and to every subject its tags belong to. |
| **Primary subject** (נושא ראשי) | The one subject that labels an article: the label above the headline, the breadcrumb, the SEO section. A roundup that spans several subjects has none. |
| **Tag** (תגית) | A specific entity (league, team, player, competition) in the central tag registry. Each tag belongs to one subject, chosen by the Admin. Renaming or deleting a tag applies everywhere it is used. |
| **Inbox** (ממתינות לשיבוץ) | Tags with no subject yet, waiting for the Admin to place them. |
| **Format** (סוג) | What kind of piece an article is, independent of its subject: story (כתבה), roundup (סיכום), guide (מדריך). |
| **View** (צפייה) | One reader opening an article page. Counted best-effort from the reader's browser; a ranking signal, not analytics. |
| **Trending** (הנקראות ביותר) | Articles ranked by views received in the trailing 7 days — not all-time totals. |
| **Related** (עוד באותו נושא) | Articles sharing tags with the current one, ranked by tag overlap, then trending views, then recency. |
| **Mid-article recirculation** | The small Related module inserted inside an article's body near the first screen; only appears in articles long enough to carry it. |
| **End-of-article recirculation** | The two labeled rows after an article: Related and Trending. An article never appears twice on the same page. |
| **Player bar** (נגן) | The persistent site-wide audio player carrying the latest episode. There is exactly one player; it survives navigation between pages. |
| **Admin** (מנהל) | The single password-holder who manages articles and tags. |
