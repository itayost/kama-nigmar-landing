# Integer Article URLs

Date: 2026-08-07
Status: Approved

## Problem

Article slugs are generated by letter-by-letter Hebrew transliteration
(`src/lib/slug/transliterate.ts`). Hebrew script omits vowels, so titles come out
as unreadable consonant strings, e.g.
`/articles/kmh-ngmr-sykvm-hshbv-2-6-8` for "כמה נגמר – סיכום השבוע". The slugs
are bad for readers, sharing, and SEO, and the admin has to hand-fix them.

## Decision

Articles are addressed by an automatically assigned integer. The canonical
article URL is `/articles/<number>` (e.g. `/articles/7`). No slug authoring at
all; the transliteration machinery is removed.

## Schema

- Add `number` to `articles`: `integer GENERATED ALWAYS AS IDENTITY`, with a
  unique index. Postgres backfills existing rows with sequential values during
  the `ALTER TABLE`.
- Keep the existing `slug` column but make it nullable. It becomes legacy data
  used only for redirecting old URLs. New articles never receive a slug.

## Routing

The `[slug]` route param in `src/app/(site)/articles/[slug]/page.tsx` is
inspected:

- All digits (`/^\d+$/`) → look up by `number`; render the article or 404.
- Anything else → look up by legacy `slug`; if found, 301 (permanent) redirect
  to `/articles/<number>`; otherwise 404.

## Admin

- Remove the slug field from `ArticleForm.tsx`; the number simply exists after
  creation and can be displayed read-only where useful.
- Delete `src/lib/slug/transliterate.ts`, `transliterate.test.ts`, and
  `SlugField.tsx`.
- Remove slug validation, the slug-uniqueness pre-check, and the Hebrew
  "slug taken" error handling from `src/lib/actions/articles.ts`.

## Link and key migration

Everything that builds article URLs or keys switches from `article.slug` to
`article.number`:

- `ArticleCard`, `ArticleMiniCard`, `ArticleLeadCard`
- `sitemap.ts`, `feed.xml/route.ts`
- `ShareButton`, `ViewTracker`, recirculation
- `api/articles/view` (accepts the article number instead of a slug)
- Cache tags: `article-${slug}` becomes `article-${number}`

## Testing

- Unit tests for the numeric-vs-legacy lookup split in the article page (or the
  data-access helper behind it): numeric hit, numeric miss, legacy slug
  redirect, legacy slug miss.
- Update e2e flows that navigate to articles by slug to use numeric URLs.
- Delete `transliterate.test.ts` along with its module.

## Out of scope

- Renumbering or vanity URLs.
- Any change to poll, tag, or admin routing.
